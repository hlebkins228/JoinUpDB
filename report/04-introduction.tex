\chapter*{ВВЕДЕНИЕ}
\addcontentsline{toc}{chapter}{ВВЕДЕНИЕ}

Для организации совместного досуга необходимо хранить сведения о мероприятиях, времени и месте проведения, участниках и отзывах. Размещение объявлений в общей ленте затрудняет поиск по заданным условиям и учет участников. Эти задачи решает специализированное приложение с базой данных.

Цель работы -- спроектировать и реализовать базу данных для поиска и организации досуга и приложение для взаимодействия с ней.

Для достижения поставленной цели необходимо выполнить следующие задачи:
\begin{enumerate}[label=\arabic*)]
    \item проанализировать предметную область и известные решения;
    \item определить требования, сущности и связи между ними;
    \item спроектировать БД, ограничения целостности, роли и триггер сохранения истории удаления объявлений, проверить соответствие БД третьей нормальной форме;
    \item выбрать средства реализации и разработать приложение;
    \item описать методы тестирования и проверить корректность основных операций;
    \item исследовать время поиска мероприятий по городу и диапазону дат с индексом по этим полям и без него.
\end{enumerate}
