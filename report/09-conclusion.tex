\chapter*{ЗАКЛЮЧЕНИЕ}
\addcontentsline{toc}{chapter}{ЗАКЛЮЧЕНИЕ}

Цель работы достигнута: спроектированы и реализованы база данных для поиска и организации досуга и приложение для взаимодействия с ней. Для достижения поставленной цели были выполнены следующие задачи:
\begin{enumerate}[label=\arabic*)]
    \item проанализированы предметная область и известные решения;
    \item определены требования, сущности и связи между ними;
    \item спроектированы БД, ограничения целостности, роли и триггер сохранения истории удаления объявлений, обосновано соответствие БД третьей нормальной форме;
    \item выбраны средства реализации и разработано приложение JoinUp;
    \item описаны методы тестирования, проверены создание мероприятия, три ограничения БД, права ролей и работа триггера; результаты совпали с ожидаемыми;
    \item исследовано время поиска мероприятий с индексом по основным фильтрам и без него.
\end{enumerate}

В результате исследования установлено, что во всех рассмотренных наборах данных индекс уменьшает среднее время выполнения основного запроса поиска. При 10000~мероприятий время составило 4,905~мс без индекса и 3,038~мс с ним, то есть сократилось примерно на 38\%. Полученный результат относится к условиям проведенного исследования.
