# Оставшиеся действия перед сдачей РПЗ

- После получения рекомендованной руководителем оценки указать ее на титульном листе в `title.tex` и выполнить `make report`. В используемом шаблоне отдельного аргумента оценки нет; последние два аргумента `\makecourseworktitle` относятся к консультантам.
- Подписанное задание пользователь подшивает к бумажной РПЗ самостоятельно. Не подключать его к `report.tex`. При окончательной печати сверить число листов в реферате с бумажным экземпляром: PDF содержит 32 страницы без листа задания.

В технологической части размещены снимки поиска, карточки мероприятия и профиля; редактирование описано текстом. Проверены создание мероприятия через HTTP-обработчики и три ограничения БД. Участие, добавление отзыва через HTTP и сценарии в браузере не проверялись. Титульный лист согласован с установленным классом bmstu; формат A4 задан явно. Основной PDF пересобран со всеми изменениями.
