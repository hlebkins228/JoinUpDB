# Оставшиеся действия перед сдачей РПЗ

- После получения рекомендованной руководителем оценки заполнить последнее поле `\makecourseworktitle` в `report.tex`. Сейчас поле пустое; оценка не выдумана.
- Подписанное задание пользователь подшивает к бумажной РПЗ самостоятельно. Не подключать его к `report.tex`. При окончательной печати сверить число листов в реферате с бумажным экземпляром: PDF содержит 39 страниц без листа задания.

Четыре предоставленных снимка интерфейса уже размещены в технологической части. Текст, список источников и PDF собраны; сценарии записи через HTTP в описанную проверку не входили.
